# 06_publications: Publication Pipeline

**Purpose:**  
This workstream contains all publication artifacts: manuscripts, figures, tables, supplementary materials, and presentations.
It is where research findings are prepared for peer-reviewed dissemination.

**Relationships:**  
- `01_science/` provides the research program, questions, and roadmap
- `03_evidence/` provides the data and findings to be published
- `04_literature/` provides citations and related work context
- `05_experiments/` provides the methodology and results

**Inputs:**  
- Evidence and analysis results
- Benchmark scores and visualizations
- Literature citations
- Research questions and hypotheses

**Outputs:**  
- Manuscripts for peer-reviewed venues
- Publication-ready figures
- Structured tables
- Supplementary materials
- Conference presentations

---

## Directory Structure

| Directory | Contents |
|-----------|----------|
| `papers/` | Manuscript drafts and submitted papers |
| `figures/` | Publication-ready figures (high-resolution PNG/SVG) |
| `tables/` | Structured data tables in Markdown and CSV |
| `supplementary/` | Supplementary materials for publications |
| `presentations/` | Conference and workshop presentations |

## Publication Workflow

1. **Outline:** Manuscript structure based on venue requirements
2. **Draft:** Write manuscript using evidence from `03_evidence/` and `05_experiments/`
3. **Figures:** Generate publication-ready visualizations
4. **Tables:** Create structured data tables
5. **Review:** Internal review for accuracy and completeness
6. **Submit:** Submit to target venue
7. **Revise:** Address reviewer feedback
8. **Publish:** Deposit final version and supplementary materials

## Open Science Practices

All publications follow open science practices:
- Preprints posted before submission
- Data and materials shared where ethically permissible
- Analysis protocols documented
- Preregistration of confirmatory hypotheses
