# 05_experiments: Executable Science

**Purpose:**  
This workstream contains all experimental protocols, templates, analysis scripts, and results for CRG-ANL pilot studies.
It is where the scientific program defined in `01_science/` is executed.

**Relationships:**  
- `01_science/` provides the study protocol, research questions, and hypotheses
- `02_engineering/` provides the schemas, instrumentation, and pipeline designs
- `03_evidence/` receives the evidence generated by experiments
- `06_publications/` communicates the findings from experiments

**Inputs:**  
- Study protocols
- Observation schemas
- Benchmark taxonomy
- Research questions and hypotheses

**Outputs:**  
- Executed pilot protocols
- Collected evidence
- Analysis results
- Research reports

## Pilot Naming Convention

`pilot_{NNN}_{descriptive_name}/`

Example: `pilot_001_quantic_longitudinal/`

## Experiment Lifecycle

1. **Design:** Protocol written, hypotheses preregistered, instruments prepared
2. **Execution:** Data collection following the study protocol
3. **Analysis:** Evidence coded, benchmarks applied, results generated
4. **Reporting:** Findings documented, limitations acknowledged, conclusions drawn
5. **Archival:** All artifacts deposited in appropriate workstreams
