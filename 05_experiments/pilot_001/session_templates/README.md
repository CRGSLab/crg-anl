# Session Templates

**Purpose:** Copy-paste-ready templates for every artifact created during a Pilot 001 session.

**How to use:**
1. Before each session, copy the relevant template to the appropriate evidence directory
2. Rename with the correct date (YYYY-MM-DD)
3. Fill in the blanks during the session

**Files:**

| Template | Destination | Rename To |
|----------|------------|-----------|
| `baseline_template.md` | `03_evidence/observations/baselines/` | `baseline_YYYY-MM-DD.md` |
| `session_log_header.md` | `03_evidence/observations/session_logs/` | `session_log_YYYY-MM-DD_HHMM.md` |
| `post_session_template.md` | `03_evidence/observations/post_sessions/` | `post_session_YYYY-MM-DD.md` |
| `observation_yaml_template.yaml` | `03_evidence/observations/coded/` | `obs_YYYYMMDD_NNN_<construct>.yaml` |

For the full step-by-step workflow, see [`../../QUICKSTART.md`](../../QUICKSTART.md).
