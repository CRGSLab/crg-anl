# Monthly Reports

**Purpose:** Structured monthly analysis reports summarizing observations, benchmark scores, trends, and methodology assessments.

**Naming convention:** `monthly_report_NN_YYYY-MM.md`

Where:
- `NN` = month number within Pilot 001 (01, 02, 03...)
- `YYYY-MM` = year and month

**Frequency:** One report per month, generated on the first Sunday of each month.

**Content (per `pilot_report_template.md`):**
- Session and observation summaries
- Benchmark scores per primary dimension
- Longitudinal trends
- Construct validation evidence
- Taxonomy stress test results
- Methodology assessment
- Decisions and changes

**First report target:** Month 1 (after first 4 weeks of data collection)
