# Project Governance

**Artifact:** Governance  
**Version:** 0.1.0  
**Status:** Active  

---

## Roles

### Principal Investigator

- Overall scientific direction and quality
- Final approval of all canonical artifacts
- Authorship decisions
- External communication and representation

### Researcher (Subject)

- Data collection following study protocol
- Observation coding and evidence deposition
- Weekly and monthly analysis
- Research memo writing

### Contributors (Future)

- Scientific critique and feedback
- Literature annotations
- Construct refinement proposals
- Decision record contributions

## Decision-Making Process

1. **Scientific decisions** (constructs, taxonomy, protocol): Principal Investigator decides, documented in decision log
2. **Methodological decisions** (instruments, schemas, analysis): Principal Investigator decides with input from evidence
3. **Operational decisions** (scheduling, workflow): Researcher decides, documented if affecting protocol
4. **Publication decisions** (venue, timing, authorship): Principal Investigator decides

## Contribution Review

All contributions to canonical artifacts require:
1. Issue or discussion opened describing the proposed change
2. Scientific rationale provided
3. Impact on existing artifacts assessed
4. Principal Investigator review and approval
5. Decision recorded in decision log (if architectural)

## Communication

- **Issues:** Bug reports, feature requests, scientific critiques
- **Discussions:** Questions, ideas, literature sharing
- **Pull requests:** Proposed changes to artifacts (require review)
- **Private inquiries:** [researcher-email@domain.com]

## Version Control Practices

- All canonical artifacts are version-controlled in Git
- Meaningful commit messages referencing affected artifacts
- Semantic versioning for major artifacts
- No direct commits to main branch (review required)
