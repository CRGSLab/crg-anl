# 04_literature: External Scientific Knowledge

**Purpose:**  
This workstream contains external scientific knowledge that informs the CRG-ANL Research Program.
It includes papers, books, platform documentation, standards, annotated bibliographies, and reading maps.

**Relationships:**  
- `01_science/` uses literature to ground construct definitions and research questions
- `05_experiments/` uses literature to inform pilot design and methodology
- `06_publications/` uses literature for citations and related work sections

**Inputs:**  
- Scholarly publications
- Books and monographs
- Platform documentation
- Technical standards
- Community resources

**Outputs:**  
- Annotated bibliography entries
- Reading maps showing literature relationships
- Synthesized literature reviews
- Citation libraries

---

## Directory Structure

| Directory | Contents |
|-----------|----------|
| `papers/` | PDF copies of scholarly papers (not version-controlled; see `.gitignore`) |
| `books/` | PDF copies of relevant books (not version-controlled) |
| `quantic/` | Quantic platform documentation, curriculum descriptions, terms of service |
| `standards/` | Relevant technical and educational standards (WCAG, IEEE, etc.) |
| `annotated_bibliography/` | Annotated entries for all key sources |
| `reading_maps/` | Visual maps showing literature relationships and coverage |

## Annotated Bibliography Format

Each entry includes:
- Full citation (APA format)
- Summary (2-3 sentences)
- Relevance to CRG-ANL (which constructs, questions, or methods)
- Critical assessment (strengths, limitations, gaps)
- Key quotes or findings

## Reading Maps

Reading maps are Mermaid diagrams showing:
- Citation relationships (who cites whom)
- Thematic clusters (papers grouped by topic)
- Coverage gaps (areas with insufficient literature)
- CRG-ANL positioning (where our contributions fit)
