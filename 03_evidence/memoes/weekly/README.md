# Weekly Memos

**Purpose:** Research memos documenting patterns, surprises, protocol issues, and emerging themes from each week of data collection.

**Naming convention:** `memo_week_NN_YYYY-MM-DD.md`

Where:
- `NN` = week number (01, 02, 03...)
- `YYYY-MM-DD` = date of the last session in that week

**Frequency:** One memo per week, written after the last session of the week (typically Sunday).

**Template:** See `01_science/measures_and_instruments.md` Section 5 (Structured Research Notes) or `QUICKSTART.md` Weekly Review section.

**Content:**
- Sessions and observations summary
- Patterns observed
- Protocol issues encountered
- Construct reflections
- Taxonomy stress observations
- Next week focus
