# Session Logs

**Purpose:** Real-time event logs captured during learning sessions.

**Naming convention:** `session_log_YYYY-MM-DD_HHMM.md`

Where `HHMM` is the session start time in 24-hour format.

**Content:** Timestamped event descriptions with context, system response, researcher reaction, trigger classification, and screenshot references.

**Created:** During every session. See `QUICKSTART.md` Phase 2.
