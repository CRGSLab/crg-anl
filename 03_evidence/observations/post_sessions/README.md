# Post-Session Forms

**Purpose:** Post-session instruments including NASA-TLX, subjective scales, and structured research notes.

**Naming convention:** `post_session_YYYY-MM-DD.md`

**Content:**
- NASA-TLX workload ratings (6 dimensions, 0-100)
- Subjective scales (14 items, 1-7)
- Structured research notes (confusion moments, momentum/friction, support effectiveness, safety moments, surprises)

**Created:** Immediately after every session. See `QUICKSTART.md` Phase 3.
