# Screenshots

**Purpose:** Visual evidence supporting observation records.

**Storage structure:**
```
screenshots/
  └── YYYY-MM-DD/
        ├── screenshot_001_description.png
        └── ...
```

**Naming convention:** `screenshot_NNN_brief_description.png`

**Guidelines:**
- Capture incorrect explanations, confusing UI states, error messages, transitions, assessment ambiguity
- Do NOT capture personal information, payment details, or other students' data
- Reference screenshots in observation YAML via `supporting_evidence` array

**Created:** During sessions as notable events occur. See `QUICKSTART.md` Phase 2.
